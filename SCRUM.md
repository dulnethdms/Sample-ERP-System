# Scrum plan

Sprint 1: foundation/auth/RBAC.
Sprint 2: users/organization/CRM.
Sprint 3: products/inventory.
Sprint 4: purchasing.
Sprint 5: sales/invoices/payments.
Sprint 6: accounting.
Sprint 7: HR/attendance/leave/payroll.
Sprint 8: reports/notifications/audit UI.
Sprint 9: API/integration tests/security.
Sprint 10: performance/deployment.

Definition of Done: database, validation, authorization, UI, API where applicable, error handling, audit logging where required, tests and documentation.
